# AnimeBook 章节制作

第一章 `site/ch01/index.html` 是用户认可的样板，第二章沿用同一套约定（“非常接近我们想要的”）。新章节要达到同样的质量，并沿用同样的交互约定。先读 `plan.md` 和 `CLAUDE.md`；本技能讲的是**怎么做**，以及第一章踩过的坑。

## 用户已拍板的约定（不要回退）

- **一块画面**：整页只有一块 16:9 画面（1600×900 舞台 + 60 高控制条），不在画面外另放练习区。
- **全部在屏幕上完成**：不设纸笔任务。需要示范计算时写成讲解例题。
- **小测插在讲解中途**，只考已经讲过的内容；尽量让学生直接操作画面里的数学对象（点数轴、拖进集合图），而不是只点文字选项。
- **两个练习不能接连出现**（小测后面至少隔一段讲解）；例外是结尾的整章练习组。
- **结尾的整章练习**每组全屏，标“Chapter practice N of M”，最后是成绩页。
- **答题有画面动画**：答对让相关数学对象动起来（点跳动、圈层依次亮、画出跳步弧线），答错抖动并给出针对这个错误的解释，可“Show answer”。
- **角色**是 SVG 画的无穷符号 ∞（`mascotEl`），只出现在小测卡片和结束页。不用狗狗素材，不用 π（有知名 YouTuber 在用）。
- **字幕**：CC 按钮或 C 键，默认关，逐句显示旁白；讲解主要靠画面内文字。
- **键盘**：拖拽之外的所有操作都要有快捷键，按钮上标出按键，`?` 列出全部。新题型必须同时给出键盘操作。
- **语言与语气**：先做英文，中文最后补；面向初一左右，语气不幼稚。
- **数学约定**：natural numbers 从 1 开始，whole numbers 含 0；同一个数可属于多个集合。
- **原书只作参考**：不截图、不照搬题干和讲解；读书页时留意原书错误（第一章就有三处），改写时修正并告诉用户。

## 制作流程

1. **读书页**：`book_pages/chNN/`（用 `sections.json` 找页码范围）。列出知识点、原书例题、原书错误和容易超纲的地方。
2. **分镜**：把内容拆成若干“步”（beat），每步一段旁白（通常 5–30 秒）加一组画面动作。确定小测插在哪里、考什么、怎么操作画面对象、答对答错时画面怎么动。大改前把分镜要点给用户过目。
3. **讲稿**：写进 `content/chNN/narration.en.json`。在需要画面同步的词前面放 `[[mark]]`，例如 `"you say [[c1]]one, [[c2]]two"`。旁白要把数学读成口语（“negative seven halves”），画面上再写成符号。
4. **生成语音**（需联网，只重做改动过的步）：
   ```sh
   uv run --with edge-tts tools/tts.py content/chNN/narration.en.json site/chNN/audio/en
   ```
   输出每步 MP3 与 `timings.js`（时长、mark 时间、逐句字幕）。
5. **写步骤代码**：见 `references/engine.md`。动作时间一律用 `m('mark', 偏移)` 或基于时长 `D`，不要手写秒数去猜语音。
6. **截图审阅**：启动 `python3 -m http.server 8765 -d site`，用 `?beat=N&t=秒` 定格任意时刻；逐步看首尾画面，检查遮挡、标签重叠、数学位置是否准确。截图时一次一个浏览器进程（并行会拖慢加载，画面停在半截），`t` 设在淡入完成之后。
7. **端到端检查**：参照 `tools/e2e_ch02.py` 写 `tools/e2e_chNN.py`，用纯键盘把每道题走一遍，覆盖答对、答错、看答案三种情况，最后逐步快进全部步骤；控制台不能有报错。有拖拽题时，参照 `tools/e2e_ch01.py` 补一遍鼠标操作。
8. **更新文档**：`plan.md` 记录新决定，`CLAUDE.md` 更新目录地图。提交前先问用户。

## 第一章踩过的坑

- **重播靠快进**：跳到第 N 步时，页面重建场景，再把前面每一步的 `run` 以 `evalTo(Infinity)` 瞬间执行一遍。因此 `run` 里只能用补间函数（`tw/prog/show/draw…`）排动作，不能用 `setTimeout`、随机数或读取当前时间，否则跳步后画面和正常播放不一致。交互元素只能在 `ask` 里创建。
- **画面时钟跟随音频**：播放时 `P.t = audio.currentTime`。用 Python `http.server` 测试时，它不支持 Range 请求，给 audio 设 `currentTime` 会跳回开头；测试请让音频自然播完。
- **小测提前继续**：学生答完直接继续时，本步还没播完的补间要先收尾（`evalTo(Infinity)`），否则淡出做一半的东西会残留到下一步。
- **拖拽**：先 `append` 把元素移到最上层，再 `setPointerCapture`；移动 DOM 节点会丢失指针捕获。
- **BEATS 里的对象字面量在定义时求值**：被引用的常量（卡片位置、`$m` 等）必须定义在 `BEATS` 之前。
- **布局分区**（避免挡住数学）：数轴 `Y0 = 610`，下方 `BAND` 卡片 y 686–886；数轴场景右上 `TOPR` 卡片不超过 470 高；集合图场景右栏 x ≥ 1258；字幕在 y ≈ 884 之上，小测时自动隐藏。
- **行内数学**用 `mathEl`，基线已和正文对齐；分数、根号、循环节都由 `M()` 绘制，不引入公式库。
- **斜体变量**：`M()` 会把 1–2 个字母的小写片段排成斜体变量，所以数学串里的单位（m、cm、kg）也会变斜体。单位请写成完整单词（meters），或放进 `T()` 的普通文字里。
- **斜体误判**：单字母 a、x 等在 `M()` 里总是斜体，所以普通英文句子（“3% a year”）不要放进 `M()`/`mline`，要用 `T()` 或改写成 “per year”。
- **大写变量与英文短词**：`M()` 不把 By、If、In 等看成变量，所以 `Ax + By = C` 里的 By 会是正体。写成 `B\u200By`（中间零宽空格）即可让 B、y 都变斜体。
- **grid / choice 的 parts 是 HTML 文字**：里面的算式要用 `$m(...)` 包起来才是数学排版（斜体变量、分数），普通字符串只是正文字体。
- **`BAND` 卡片放不下长填空**：一行里有多个空或文字较长时，把题拆成几行 `blanks`，并用自定义的 `{ x, y, w, cls: 'side' }` 宽卡片放在图形旁边（见 ch18 的第一次小测）。
- **引擎里已有的名字不能在章节里再用 `const` 声明**（如 `popIn`、`rect`、`eqLine`），否则整页脚本报错、画面空白。新增章节后先用 `?beat=0` 检查控制台，再跑测试。
- **结束页按 Enter 会进入下一章**；测试里要用 R 键回到开头。
- **示意图不能误导**：比例放大的图形（如利息块）必须在画面上注明“drawn larger”。
- **光标在填空框里时**，只有 Enter（检查）和 Esc（离开输入框）会被拦截，其余按键都当作打字；测试里按 S 看答案之前，要先按 Esc。
- **Playwright 选择器**：`text=Check` 不区分大小写且按子串匹配，会命中“Quick check”；按钮名里带有按键提示（“1Rational”）。请用 CSS 类或序号定位。
- **判题只看数学意义**：分类题按集合判断，顺序无关；不能凭有限位小数断言无理数；分母不能为 0；先化简再归类（√9、12/4）。

## 引擎与章节文件

通用部分在 `site/lib/engine.js` 和 `site/lib/engine.css`：播放器、绘图、题型、角色、画面框架。每章一个 `site/chNN/index.html`，只写 `CHAPTER`、本章的绘图小函数、`BEATS` 和题目数据，最后调用 `boot()`。新章节从 `site/ch02/index.html` 开始改最方便，它展示了算式、面积模型、点阵、数轴跳步等常用写法。

章节页 `<head>` 保留 `<link rel="expect" href="#bar" blocking="render">`：没有它，Chromium 常在播放器生成前就渲染首帧，目录卡片放大成画面的页面过渡会被取消。新章节做好后，在 `site/index.html` 的 `UNITS` 里加一行（标题、分钟数），章号按顺序自动编号；上一章的 `CHAPTER.next` 指向新章。

- 改引擎后，必须重跑所有已完成章节的 `tools/e2e_chNN.py`。
- 某个画法第二次用到时，再把它从章节文件挪进引擎，不要提前抽象。
