# Chapter 3 — Absolute Value

Source pages 31–36. Visual argument: absolute value is a length. An amber "distance tape" runs from 0 to the number; opposite numbers' tapes lift off the line and match; a number splits into its sign (which side) and its absolute value (how far). Bars are grouping symbols (moves on the line, then the tape), a sign outside is a flip across 0 (ch02's opposites), a number in front lays tapes end to end.

Colours: sign colours as ch02 (`POS` blue, `NEG` coral, zero chalk). `COL.task` amber = distance: tapes, hop counts and the absolute value bars themselves. Number line −8…8, `AXIS.u = 80` (as ch02).

## Errata / source changes
- The book says "the absolute value is always positive". Corrected to "never negative" (positive or 0), since |0| = 0; the lesson shows |0| = 0 and final1 asks it.
- Examples re-created: |9| → |7| (fits the −8…8 line); −|−16| → −|−7|; Johanne's −$56.50 → Maya's −$42.75; the 94 ft valley → diver at −30 ft. Kept from the book: |−4| = 4, |5 − 3| = |2| = 2, −|6| = −6, 2|−4| = 2 · 4 = 8, the four ways to write multiplication, ab, 3x and the definition of a variable (the book's "3x = 15" and "ab = 8" become "3x = 3 · x" and "ab = a · b", since solving is not taught yet).
- Practice uses new numbers (book: 19, 49, 4.5, 1/5, 4, 5, −65, −9, 56.50, 94).
- Added (consistent with the source): opposites have the same absolute value; sign = which side, absolute value = how far; the common mistake −|−7| ≠ 7.
- Inside-the-bars work is kept to results ≥ 0 (5 − 3, 6 − 2, 9 − 4, 3 · 4): subtracting into negatives is ch12.
