## Verified answers (used in the lesson)
- Ex. 1.1: u = e^{−t} sin x. Ex. 1.3: u = (1 − e^{−t}) sin x + e^{−4t} sin 2x (T₁′ + T₁ = 1, T₁(0) = 0; T₂′ + 4T₂ = 0, T₂(0) = 1).
- Ex. 1.2: f_k = 2(1 − (−1)^k)/(πk); T_k = f_k(1 − e^{−k²t})/k²; u = Σ_{n≥1} 4(1 − e^{−(2n−1)²t}) sin(2n − 1)x / (π(2n − 1)³). Limit t → ∞: Σ 4 sin(2n−1)x/(π(2n−1)³) = x(π − x)/2 (the solution of −u″ = 1, u(0) = u(π) = 0; standard sine series of x(π − x) = (8/π)Σ sin(2n−1)x/(2n−1)³).
- Equation beat profile: u = c + A e^{−4t} sin 2x solves u_t = u_xx on [0, π] with ends at c (shown with a² = 1).
- Decay beat: u = e^{−t} sin x + ½ e^{−9t} sin 3x.
- Problem 1: e^{−t} sin x − e^{−9t} sin 3x. Problem 2: sin³x = ¾ sin x − ¼ sin 3x, u = ¾ e^{−t} sin x − ¼ e^{−9t} sin 3x, so u(π/2, t) = ¾ e^{−t} + ¼ e^{−9t}.
- Problem 5: T′ + T = e^{−t}, T(0) = 0 → T = t e^{−t}; u = t e^{−t} sin x.
- Problem 8: w = t, F = 1 − 1 = 0, Φ = sin x → u = e^{−t} sin x + t.
- Problem 9: w = −2x, Φ = 2 sin x, T′ + T = t e^{−t}, T(0) = 2 → T = (t²/2 + 2)e^{−t}; u = (t²/2 + 2)e^{−t} sin x − 2x.
- Problem 10: w = 3x, Φ = −2 sin 2x, a²λ₂ = 4·4 = 16, T′ + 16T = t e^{−16t}, T(0) = −2 → T = (t²/2 − 2)e^{−16t}; u = (t²/2 − 2)e^{−16t} sin 2x + 3x.
- q2: sin x with 0/0 — yes; cos x with 1/1 — no (cos π = −1); 3x − 2 sin 2x with 0/3π — yes; 1 + x with e^{−t}/1 — no (φ(π) = 1 + π).

## Errata and notes for the user
- Ex. 1.2 (p. 16) writes the odd-term series with summation index `l`, which is also the rod length; the lesson uses `n`.
- p. 13: "является базисом в пространстве непрерывных на [0, l] функций" — the sine system is a basis in the mean-square sense (L²), not for uniform convergence of every continuous function (a function with φ(0) ≠ 0 cannot be a uniform limit of sines). The lesson says "любую разумную функцию … в смысле среднего квадратичного".
- Additions not in the book: the hump/dip explanation of the sign of u_xx, the vector-projection analogy picture, the stationary profile x(π − x)/2 in ex. 1.2.
