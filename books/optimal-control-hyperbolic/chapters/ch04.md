- u*(0,25) = −1 (p < 0), u*(0,5) = 1 (p = 0,125).

- U = [0, 2]: u*(0,1) = 0, u*(0,5) = 2, J* = −2∫_{1/3}^1 p dt = −4/27 (∫₀¹ p dt = 0).
- p(τ) = 0,1, u(τ) = −1, ū = 1: ΔJ ≈ −0,2ε.
